# 斤两换算（Weight-Volume）

斤、两、克、毫升、立方厘米、杯、磅、品脱、斗、合等 63 个重量与容量单位的换算：常用的 21 个一屏看全，其余 42 个收在「更多单位」里；每行 3 格都是同一类，并且从左到右由小到大（如立方厘米 → 立方分米 → 立方米）。可以按物质（水、牛奶、面粉……）在重量和容量之间互换。

「生活物品」卡有 18 格：输入几个鸡蛋、几张 A4 纸、几张人民币、几罐可乐、几袋水泥……所有单位一起算出多重；反过来输入斤两也能看出合几个鸡蛋。换算区底下还会提示「相当于 1.5 罐可乐」。

在线地址：<https://fjkkx77.github.io/Weight-Volume/>
灵感来源：[data-Calculation](https://fjkkx77.github.io/data-Calculation/)

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 界面（样式与交互都在这里） |
| `data.js` | 只放数据：单位、物质密度、物品，**每条都带出处和可信度** |
| `convert.js` | 只放计算：浏览器和 node 共用，不碰页面 |
| `pull-to-refresh.js` | 下拉刷新组件，原样复用，参数不要改 |
| `tools/stamp.cjs` | 给 `index.html` 引用的 js 打内容指纹（`?v=`），**改完任何 js 都要跑一次** |
| `tests/convert.test.cjs` | 计算与数据完整性测试 |
| `tests/stamp.test.cjs` | 指纹是否最新（忘了跑 stamp 会报红） |
| `tests/ui.verify.cjs` | 真实手机视口测试（320 / 390 / 430 宽，浅色 / 深色；含「一屏看全」判据、每键耗时） |
| `tests/lib/cdp.js` | 零依赖的 headless Chrome 驱动（跨系统，CI 用） |
| `.github/workflows/test.yml` | 每次推送在 GitHub 上自动跑上面两套测试 |

零外部依赖，直接双击 `index.html` 也能用。

## 跑测试

需要 Node 22 以上和 Chrome（找不到时设 `CHROME_PATH`）。

```bash
node tools/stamp.cjs                     # 改过 js 之后先更新指纹
node --test "tests/*.test.cjs"           # 计算 + 数据 + 指纹（没写出处的数据会被拦下）
node tests/ui.verify.cjs [截图目录]       # 自己起本地服务器，一条命令跑完
```

| 港斤 604.78982 克 | 香港《度量衡条例》第 68 章 |
| 台斤 600 克 | 台湾市场通行值（第三方资料，**未取得官方条文**，可信度中） |
| 各种物质的密度 | FAO/INFOODS Density Database v2.0 |
| 乒乓球 2.7 克 | 国际乒联规则 2.3.3 |
| A4 纸 4.99 克；整包 500 张 2494.8 克 | ISO 216 尺寸 210×297 毫米 × 80 克/平方米；一包 500 张为包装标称 |
| 公制茶匙 / 汤匙 / 杯 | 国际通行值；**未查到中国统一的量具国家标准** |
| 鸡蛋 61 克（生活物品格） | SB/T 10638-2011《鲜鸡蛋、鲜鸭蛋分级》中等蛋 M 级单枚 58～64 克，**取中值**（用户 2026-10-08 选；原先取每 100 枚 ≥ 5.9 千克的下限 59 克会系统性偏少）；分级表经 [T/GDFCA 048-2020](https://www.ttbz.org.cn/upload/file/20200818/6373334334376986764697854.pdf) 表 2 转引核对，**SB/T 原文未取得**（2026-10-08） |

| 袋装水泥 50 千克 | GB 175-2007《通用硅酸盐水泥》9.4「袋装水泥每袋净含量为 50kg」（多处转引一致；**2023 版条文原文未取得**） |
| 饮料、桶装油、桶装水的重量 | 包装标称容量 × 内容物密度（牛奶 1.03、食用油 0.92、可乐按水近似），密度出自 FAO/INFOODS；**不跟随页面上选的物质** |

生活物品只收标准规定或包装上印着标称值的物品，不收经验估计（避免歧义）；唯一例外是人民币（标明「非官方实测」）。每一列按什么规格算写在分组标题里。原来单独的「生活参照」卡 2026-10-08 并进了物品格。
