# 换算合集（Weight-Volume）

2026-10-09 起从「斤两换算」扩成换算合集：首页 `index.html` 是目录，每种换算一个页面，点页面标题可以直接切到别的换算。
共 12 种：**重量·容量**（`weight.html`，原斤两换算）、**长度**、**面积**、**温度**、**货币**、**速度**、**角度**、**油耗**、**能量**、**功率**、**压力**、**力**（第一批前 4 种，第二批后 8 种，都在 2026-10-09 上线）。
所有换算页共用同一套网格：任意一格输入、其余自动算出，常用单位一屏看全、其余收在「更多单位」里，每行同类、从小到大。

## 斤两换算（weight.html）

斤、两、克、毫升、立方厘米、杯、磅、品脱、斗、合等 63 个重量与容量单位的换算：常用的 21 个一屏看全，其余 42 个收在「更多单位」里；每行 3 格都是同一类，并且从左到右由小到大（如立方厘米 → 立方分米 → 立方米）。可以按物质（水、牛奶、面粉……）在重量和容量之间互换。

「生活物品」卡有 24 格：输入几个鸡蛋、几张 A4 纸、几张人民币、几枚硬币、几罐可乐、几袋水泥……所有单位一起算出多重；反过来输入斤两也能看出合几个鸡蛋。换算区底下还会提示「相当于 1.5 罐可乐」。

在线地址：<https://fjkkx77.github.io/Weight-Volume/>
灵感来源：[data-Calculation](https://fjkkx77.github.io/data-Calculation/)

### 加一个换算页

1. 写 `data-<id>.js`（照 `data-length.js`：groups + units，每条 source / level；温度这类带偏移的给 `to` / `from`）
2. 在 `pages.js` 加一条（`dataVar` 填 data 文件挂的变量名；要输入负数加 `signed: true`）
3. `node tools/build-pages.cjs`，然后在 `tests/ui.verify.cjs` 的 `checks` 里给这页加几个换算样例
4. 跑两套测试

## 跑测试

需要 Node 22 以上和 Chrome（找不到时设 `CHROME_PATH`）。

```bash
node tools/build-pages.cjs               # 改过 pages.js 或页面版式后重新生成
node tools/stamp.cjs                     # 改过 js / css 之后更新指纹
node --test "tests/*.test.cjs"           # 计算 + 数据 + 指纹（没写出处的数据会被拦下）
node tests/ui.verify.cjs [截图目录]       # 自己起本地服务器，一条命令跑完
```
