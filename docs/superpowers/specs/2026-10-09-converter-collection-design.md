# 换算合集（第一批）设计稿 · 2026-10-09

> 用户 2026-10-08 提出：①补人民币硬币；②把斤两换算扩成「换算合集」，每种换算单独一个页面，由主界面链接跳转/切换，
> 换算方式和现有重量/容量一样，数据查官方权威来源。用户选定：硬币收、标非官方实测；网址首页变目录；
> 货币用人民币中间价为主；分两批做。温度第二行收历史单位（选 A）。

## 1. 范围

- 第一批：共用引擎 + 目录首页 + 斤两页搬到 `weight.html`（加硬币）+ 长度 / 面积 / 温度三页。
- 第二批（另起设计）：角度、货币、能量、力、油耗、功率、压力、速度。

## 2. 结构

| 文件 | 作用 |
|---|---|
| `index.html` | 目录：2 列格子，只列已上线的换算（不放「制作中」空入口） |
| `weight.html` | 原斤两换算，功能不变 |
| `length.html` `area.html` `temperature.html` | 由 `tools/build-pages.cjs` 按 `pages.js` 生成（版式只有一份源头） |

| `grid.js` | 网格引擎：渲染、起点格、同行字号、缩字号、更多单位、状态保存、归零、± 键 |

**切换方式的调整（实施时发现）**：斤两页首屏 21 格底边离「≤ 屏高 85%」判据只剩 18px，
再加一行「‹ 全部换算」会把首屏挤爆。所以返回和切换都收进**标题本身**：点「斤两换算 ⌄」弹出菜单，
第一项是「全部换算」，下面是各个换算。不占高度，每页一致。

## 3. 换算模型

- 单位二选一：`toBase`（乘倍数）或 `to` / `from`（函数，温度用；第二批油耗的倒数关系也用它）。
- 温度允许负数；iPhone 数字键盘没有减号，页面标题栏加「±」键（按下不抢焦点、键盘不收起）。
- 低于绝对零度：起点格标红，其他格清空，提示行说明原因。

## 4. 单位表（每行同类、从小到大；温度不判大小顺序）

长度（米为基准）：常用 毫米·厘米·米 / 千米·英里·海里 / 寸·尺·里（市制）/ 英寸·英尺·码；
更多 纳米·微米·分米 / 厘·分·丈 / 英寻·杆·弗隆 / 天文单位·光年·秒差距。

面积（平方米为基准）：常用 平方厘米·平方分米·平方米 / 公亩·公顷·平方千米 / 分·亩·顷 / 平方英尺·平方码·英亩；
更多 平方寸·平方尺·平方丈 / 平方英寸·平方杆·平方英里 / 坪·台分·甲（台湾民间通行）。

温度：常用 摄氏度·华氏度·开尔文；更多 兰氏度·列氏度·罗氏度（后两个标历史单位）。

硬币（斤两页物品卡，人民币纸币之后）：1 分·2 分·5 分 / 1 角·5 角·1 元（2019 版），标非官方实测、不进推荐。

出处：国际单位制 GB 3100-1993；NIST SP 811 附录 B（英美单位、温度公式）；1929《度量衡法》第五、六条
（尺 = 1/3 米、里 = 1500 尺、亩 = 6000 平方尺）；IAU 2012 B2（天文单位）、IAU 2015 B2（秒差距）；
硬币 Numista / uCoin / Numisquare 目录（央行只公布直径和材质）。
